## 🌟 Brand Overview & Mission

**Creonex** is a modern digital solutions and software engineering studio dedicated to building high-performance web applications, scalable platforms, and bespoke digital products. We bridge the gap between creative visual design and robust engineering to deliver digital solutions that drive measurable business impact.

### Studio Pillars:
- **Engineered for Scale:** Clean code, modular component architecture, and high-throughput backends.
- **Human-Centric UX:** Intuitive interfaces, fluid micro-interactions, and accessible typography.
- **End-to-End Delivery:** From initial ideation and architecture design to continuous deployment and SLA-backed support.

## 💻 Local Development & Setup

### Prerequisites
- Node.js (v16+ or modern LTS recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/creonex/portfolio.git
   cd Creonex
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application in your browser.

4. **Run unit tests:**
   ```bash
   npm test
   ```

## 📦 Build & Deployment

To compile an optimized production bundle:

```bash
npm run build
```

The compiled assets will be output to the `build/` folder, ready for zero-configuration static deployment on:
- **Vercel:** Import repository and set build command to `npm run build` and directory to `build`.
- **Netlify:** Drag-and-drop the `build` directory or link Git repository.
- **GitHub Pages:** Run `npm run deploy` to publish to `gh-pages` branch.
